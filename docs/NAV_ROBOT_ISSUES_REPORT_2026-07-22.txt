1. 테이블까지 가다가 중간에 미션이 갑자기 끊김 (to_2 첫 복도 구간)
--------------------------------------------------------------------------------
현상)
  터미널에 횡오차 0.6m 넘었다는 메시지가 나오면서 주행이 멈춤.
  로봇은 아직 복도 입구 근처인데, 레일을 크게 벗어난 것처럼 판정됨.
  (예: to_2_wp1 구간)

원인)
  routes.yaml 상 복도 정렬점 (0, 5.00) 이 미션 시작 시 pose prune 로직에서
  잘려 나감. 그 결과 Nav2가 주방에서 복도 첫 점까지 직선이 아닌 대각선
  경로로 가게 되고, rail_navigator 의 cross-track 검사가 그 대각선을
  레일 이탈로 잘못 계산함.

해결)
  rail_geometry.prune_poses: 주방(x≈0.21)에서 복도(x≈0) 정렬 웨이포인트는
  거리가 가까워도 제거하지 않도록 예외 추가.
  주방→복도 진입 leg 는 rail_check.yaml 의 max_lateral_error_entry_m 으로
  CTE 한도 완화.


--------------------------------------------------------------------------------
2. 복도를 직진으로만 가면 되는데 로봇이 좌우로 흔들리며 감 (와리가리)
--------------------------------------------------------------------------------
현상)
  x=0 복도에서 앞으로만 가면 되는데, RViz·시뮬 화면에서 로봇이
  좌우로 지그재그치듯 보정하며 답답하게 움직임.

원인)
  spine 웨이포인트마다 Nav2 goToPose 를 취소하고 다음 점을 다시 보내
  경로가 매번 새로 잡힘.
  nav2_params 의 Regulated Pure Pursuit 이 lookahead 가 짧고 각가속이
  커서 직선에서도 조향 보정이 과함.

해결)
  rail_navigator: x≈0 인 연속 spine 점은 goThroughPoses 로 한 번에 추종.
  nav2_params: lookahead 확대, desired_linear_vel·max_angular_accel·
  velocity_smoother 완화.


--------------------------------------------------------------------------------
3. 테이블 옆에 붙은 뒤 뒤로 빠지지 않고, 슬롯 안에서 돌아서 나옴 (유턴)
--------------------------------------------------------------------------------
현상)
  테이블 전방 주차는 된 것 같은데, 복도로 나올 때 뒤로 직선 후진하지 않고
  자리에서 크게 돌아서 나가는 것처럼 보임. 이후 return 주행도 이상해짐.

원인)
  park_out 에서 Nav2 BackUp 이 실패하거나, 실패 후 goToPose 폴백이
  도크에서 복도 목표 (0, y) 로 가는 전진·회전 경로를 계획함.
  복도에 못 서 있는데도 return_* 미션이 시작되면 첫 목표가 복도 중앙이라
  슬롯 안에서 유턴하는 Nav2 동작이 나옴.

해결)
  reverse_open_loop: Nav2 끄고 /cmd_vel linear.x < 0 으로 직선 후진.
  |x| 가 aisle_x_max_m 이하일 때만 return_kitchen 진행, 아니면 미션 실패로
  유턴 복귀 차단.
  goToPose 폴백(유턴 유발) 제거.


--------------------------------------------------------------------------------
4. 주차 후진 단계에서 미션 전체가 실패로 끝남 (park_out)
--------------------------------------------------------------------------------
현상)
  터미널에 BackUp 1.5m 시도 후 TaskResult.FAILED, t3 exit 1.
  로봇은 테이블 앞에 그대로 있거나, 뒤로 거의 안 움직인 채 멈춤.

원인)
  Nav2 behavior_server 의 BackUp 이 후방 코스트맵·simulate_ahead 충돌
  검사에서 실패. 슬롯·테이블·의자가 후방에 잡히거나 시간 초과.

해결)
  후진은 open-loop cmd_vel 을 1차 수단으로 사용.
  필요 시 costmap clear 후 짧은 BackUp 재시도만 보조.
  backup_speed 등 rail_check.yaml 조정.


--------------------------------------------------------------------------------
5. 도착은 했는데 로봇이 테이블·주방 방향과 안 맞음 (헤딩)
--------------------------------------------------------------------------------
현상)
  목표 위치 근처에는 왔는데, 로봇 앞쪽이 테이블과 평행하지 않거나
  주방에서도 몸이 비뚤어져 있어 이후 pick&place 하기 어려워 보임.
  미션은 성공으로 끝남.

원인)
  Nav2 goal checker 가 xy 위주로 성공 처리하고 yaw_goal_tolerance 가 넉넉함.
  RPP 에서 use_rotate_to_heading: false 라 최종 자세 맞추기를 안 함.
  rail_mission 은 위치만 맞으면 다음 단계로 넘어감.

해결)
  dock·주방 등 경로 마지막 waypoint 도착 후 routes.yaml 의 yaw 에 맞춰
  Nav2 Spin (align_heading_at_dock, rail_check.yaml).
  map/base_link yaw 는 TF·AMCL 로 읽고, 오차만큼 상대 회전.

6. 팀 저장소에 Nova 주행 파일·실행법이 없어 보임
--------------------------------------------------------------------------------
현상)
  younggi 브랜치를 받아도 어디서 t1/t2/t3 하는지, Nova 패키지가
  어디 있는지 팀원이 찾기 어려움.

원인)
  실제 스택이 nav_robot2/nav_robot3 에 있는데 문서·루트 README 가
  부족했고, nav_robot 쪽 Nova 통합 파일은 미커밋 상태였음.

해결)
  docs/NOVA_CARTER.md, README, nav_robot Nova launch·미션 커밋·푸시.
  이후 실행은 nav_robot3 + 루트 tools/aliases.sh 의 t1/t2/t3 로 통일.

7. nav_robot2 쓰지 않고 t1/t2/t3 만 치면 nav_robot3 가 떠야 함
--------------------------------------------------------------------------------
현상)
  예전에 nav_robot2 aliases 를 쓰면 domain·패키지가 섞이고,
  레일 미션(nav_robot3)과 다른 스택이 실행됨.

원인)
  nav_robot2/tools/aliases.sh 와 nav_robot3 가 각각 t1/t2/t3 를 정의.
  domain 104/103 혼용.

해결)
  루트 tools/aliases.sh 가 nav_robot3/tools/aliases.sh 를 source.
  nav_robot2 aliases 는 deprecated 후 nav_robot3 로 위임.
  단일 운영 시 ROS_DOMAIN_ID=103 으로 통일.


--------------------------------------------------------------------------------
8. 로봇이 너무 느리게 다님
--------------------------------------------------------------------------------
현상)
  식당 안 주행이 답답하게 느림.

원인)
  nav2_params 의 desired_linear_vel, velocity_smoother max_velocity 가
  보수적으로 설정됨. park_out 후진 속도도 낮음.

해결)
  nav_robot2/3·nav_robot nova params 에서 선속·가속·후진 속도를 약 1.5배
  상향. 변경 후 Nav2(t2) 재시작 필요.


--------------------------------------------------------------------------------
9. (참고) 터미널에 initial pose 설정 로그가 계속 찍힘
--------------------------------------------------------------------------------
현상)
  t3 시작할 때 Setting initial pose / Waiting for amcl_pose 가
  짧은 시간에 여러 번 반복되어 보임.

원인)
  rail_mission / BasicNavigator 의 waitUntilNav2Active 가 initial pose
  를 반복 설정하거나, sync_spawn 과 중복 호출.

해결)
  publish_initial_pose + initial_pose_received 플래그로 중복 완화
  (완전 제거는 Nav2 commander 동작에 따라 추가 조정 가능).
